Today's brief Am I affected?

Version matching is approximate. A dotted version is compared with a shortened list of version ranges from NVD. Many exploited bugs in the CISA catalog have no version range, so a name match still needs a person to confirm it. This page does not send your file anywhere. It also does not scan a network. Risk notes for open Telnet, file sharing, and similar services are in the local report from scan.py, not on this page.
